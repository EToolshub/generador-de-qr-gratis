    Why these QR codes never expire

    Plenty of “free” generators make dynamic QR codes: the code points to their server, which then redirects to your link. It works until the free trial ends, and then the code you already printed stops opening. It happens to menus, flyers and packaging more often than you'd think.

    Here, link, WiFi, WhatsApp, social, contact, location, phone, SMS, email, event and text codes are static: the information is written into the code itself. Nothing sits in between, and they'd keep working even if this website went away.

    With images and PDFs there's no other way: the file has to live somewhere. We store it with no expiry date and the code opens it directly, with no ads in between.

    Tips so it scans on the first try

    • Dark code on a light background. Every camera reads that best. Inverted colors work on almost every phone, but not all of them.
    • Keep the margin. The empty border around the code is part of the QR code: don't crop it or put text right against it.
    • Make it big enough. At least 2 × 2 cm (0.8 in) up close; for posters, the scanning distance divided by 10.
    • Less content is better. A short link means bigger squares and a code that scans faster.
    • Test before printing. Especially if you added a logo, a frame or colors.

    Frequently asked questions

    Is it really free?

    Yes. No sign-up, no limit on how many codes you make, no watermark and no trial period. You can use your QR codes for your business too.

    Do the QR codes expire?

    No. Link, WiFi, WhatsApp, text, contact and the other types carry the information inside the code itself, so they work forever, even if this website disappeared. Image and PDF codes open your file, which we keep with no expiry date.

    How do I make a QR code for an image or a PDF?

    Choose Image or PDF and upload your file (up to 4 MB; photos are optimized automatically). We store it and the QR code opens it when scanned. Anyone with the code can see it, so don't upload private documents.

    Can I change the content after printing the QR code?

    No: the content is baked into the code, which is exactly why it never expires. If you think the destination will change, point the code to a page of yours that you can update, like your website or your profile.

    How big should I print it?

    At least 2 × 2 cm (0.8 in) for close-up scanning. For posters, divide the scanning distance by 10: at 2 meters (6.5 ft), about 20 cm (8 in). Below the download button we show the minimum size for your code.

    PNG or SVG?

    PNG for WhatsApp, social media and documents. SVG for print shops, vinyl and design apps: it's a vector file, so it stays sharp at any size.

    Do you store what I type or my WiFi password?

    No. The QR code is made in your own browser and nothing you type is sent to a server. The only files we store are the ones you upload under Image or PDF.

    Can I add my logo and a frame with text?

    Yes. Upload your logo or pick WhatsApp, Instagram and other network logos, and add a frame with text like “Scan me” or “View menu”. With a logo we raise error correction to the maximum so the code still scans.
